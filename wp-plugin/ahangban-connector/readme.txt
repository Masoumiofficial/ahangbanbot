لایهٔ امن اتصال ربات تلگرام آهنگ‌بان به داده‌های واقعی وردپرس، همراه با وب‌هوک داخلی برای هاست اشتراکی.

== پیش از نصب یا ارتقا ==
اعتبارنامه‌ها فقط از محیط پردازش PHP خوانده می‌شوند؛ در فرم‌های پیشخوان یا `wp_options` ذخیره نمی‌شوند. پیش از ارتقا از v1.4.0، این متغیرها را در محیط PHP-FPM/هاست تنظیم کنید:

* `AHANGBAN_API_TOKEN`: دقیقاً ۶۴ رقم hex تصادفی؛ باید با همین نام در `.env` خصوصی ربات Python یکسان باشد.
* `AHANGBAN_BOT_TOKEN`: توکن BotFather.
* `AHANGBAN_BOT_SECRET`: Secret وب‌هوک، ۱ تا ۲۵۶ نویسه از حروف انگلیسی، عدد، `-` و `_`؛ مقدار ۶۴رقمی hex توصیه می‌شود.
* `AHANGBAN_TRUSTED_PROXY_IPS`: اختیاری؛ IP/CIDR پراکسی‌های مورداعتماد برای خواندن هدرهای IP.

نمونهٔ کامل در `.env.example` مخزن است؛ فایل `.env` فقط برای سرویس Python است و WordPress آن را خودکار نمی‌خواند. برای تولید API token یا Secret از یک منبع تصادفی امن روی دستگاه امن استفاده کنید؛ مقادیر واقعی را در Git، چت یا تنظیمات عادی وردپرس قرار ندهید. نسخهٔ 1.5.0 در اجرای اول گزینه‌های قدیمی توکن API، توکن ربات و Secret وب‌هوک را از `wp_options` حذف می‌کند.

== نصب ==
1. متغیرهای محیطی PHP بالا را پیش از ارتقا تنظیم کنید.
2. ZIP افزونه را در پیشخوان وردپرس → افزونه‌ها → افزودن → بارگذاری افزونه نصب/جایگزین کنید.
3. در منوی «آهنگ‌بان API» آماده‌بودن اعتبارنامه‌ها را بررسی کنید؛ صفحه فقط وضعیت را نشان می‌دهد و مقدار Secretها را چاپ نمی‌کند.
4. شناسهٔ ادمین، یوزرنیم ربات، حالت اجرا و در صورت نیاز کانال را از همان صفحه تنظیم کنید. برای هاست اشتراکی حالت وب‌هوک را انتخاب کنید؛ Python polling روی VPS است و با وب‌هوک برای یک Bot Token هم‌زمان اجرا نمی‌شود.
5. در حالت وب‌هوک روی «ثبت وب‌هوک در تلگرام» بزنید؛ اگر از وب‌هوک به polling می‌روید، نخست وب‌هوک قبلی را حذف کنید. سپس در تلگرام `/start` را امتحان کنید.

== قابلیت‌ها ==
* REST اختصاصی با جست‌وجوی فارسی، فهرست هنرمندان، کارت اثر، جدیدترین و محبوب‌ترین‌ها.
* API عمومی Health حداقلی است؛ فقط `status: ok` را برمی‌گرداند.
* خروجی API فقط آثار منتشرشدهٔ موسیقی را در بر می‌گیرد؛ نوشتهٔ عادی یا محتوای خصوصی برگردانده نمی‌شود.
* جست‌وجو/صفحه‌بندی محدود است؛ پردازش UTF-8 بدون الزام به افزونهٔ PHP `mbstring` کار می‌کند.
* کش جزئیات آهنگ و نمایهٔ سبک هنرمندان؛ تصویر هنرمند فقط برای صفحهٔ درخواستی resolve می‌شود.
* مرتب‌سازی آثار هنرمند بر اساس عنوان پیش از صفحه‌بندی در SQL انجام می‌شود.
* ارسال صوت/ویدیو: دریافت مستقیم Telegram، سپس fallback امنِ محدود به ۴۹ MiB؛ پیوند واقعی در صورت شکست.
* اعتبارنامهٔ Telegram در درخواست‌های HTTP هیچ redirectی را دنبال نمی‌کند؛ ارسال فایل timeout مبهم را بی‌خطر retry نمی‌کند.
* اتصال اختیاری کانال با WP-Cron؛ انتشار خودکار خاموش است و نوشته‌های معمولی نادیده گرفته می‌شوند.
* پنل تلگرام: آمار، سلامت، پاک‌سازی cache، مسدودسازی و broadcast دسته‌ای با پیش‌نمایش و تأیید.
* جدول‌های آماری/صف فقط در دیتابیس موجود WordPress هستند؛ دیتابیس موازی برای داده‌های سایت ساخته نمی‌شود.

== امنیت ==
* `AHANGBAN_API_TOKEN`, `AHANGBAN_BOT_TOKEN` و `AHANGBAN_BOT_SECRET` فقط از محیط PHP خوانده می‌شوند؛ هیچ fallback به `wp_options` ندارند.
* API با Bearer token، rate limit اتمی در دیتابیس موجود، مقایسهٔ ثابت‌زمانی و IP پراکسیِ صریحاً مورداعتماد محافظت می‌شود.
* CORS wildcard حذف شده است؛ کلاینت Python سروربه‌سرور است و نیازی به CORS ندارد.
* تماس با Telegram روی HTTPS انجام می‌شود، SSL verify روشن و redirect غیرفعال است.
* وب‌هوک POST هدر `X-Telegram-Bot-Api-Secret-Token` را اجباری بررسی می‌کند؛ update تکراری یک‌بار پردازش می‌شود.
* URL رسانه باید HTTPS و مقصد عمومی باشد؛ مقصد محلی/خصوصی و redirect ناامن رد می‌شوند؛ اندازهٔ فایل محدود است.
* کانال و Health عمومی جزئیات نسخه/محیط هاست را افشا نمی‌کنند.

== تغییرات ==
= 1.5.0 =
* انتقال اعتبارنامه‌های API، Telegram و وب‌هوک به محیط PHP؛ پاک‌سازی گزینه‌های قدیمی دیتابیس در اولین اجرا.
* توقف redirect در درخواست‌های Telegram و جلوگیری از resend فایل پس از timeout یا پاسخ 5xx مبهم.
* rate limit اتمی و مقاوم به هدرهای IP جعلی؛ پشتیبانی اختیاری از allowlist پراکسی.
* حذف CORS wildcard و کاهش داده‌های Health عمومی.
* قفل صفحه‌بندی، fallback UTF-8 بدون mbstring، جست‌وجوی کم‌هزینه‌تر و فیلتر آثار موسیقی.
* کش نمایهٔ هنرمندان و resolve تصویر برای صفحهٔ جاری؛ مرتب‌سازی عنوان قبل از صفحه‌بندی.
* جلوگیری از تأیید تکراری broadcast و گم‌شدن بی‌صدای خطای query/صف WP-Cron.
* بازطراحی راست‌چین و واکنش‌گرای پنل؛ POST/Redirect/GET و حذف اسکریپت inline.

= 1.4.0 =
* رفع افت وضوح کاور و افزودن fallback اندازهٔ تصویر.
* اتصال اختیاری کانال و انتشار خودکار آهنگ‌های تازه از صف WP-Cron؛ خاموش به‌صورت پیش‌فرض.
* دکمهٔ deep-link به ربات، شمارش دسته‌های آثار و بهبود UX.
