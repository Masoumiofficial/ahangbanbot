لایهٔ امن اتصال ربات تلگرام آهنگ‌بان به داده‌های واقعی وردپرس، همراه با وب‌هوک داخلی برای هاست اشتراکی.

== نصب بدون SSH (دایرکت‌ادمین) ==
1. فایل ZIP افزونه را در File Manager → wp-content/plugins آپلود و Extract کنید.
2. در پیشخوان وردپرس → افزونه‌ها، AhangBan Connector را فعال کنید.
3. به منوی «آهنگ‌بان API» بروید و در بخش «تنظیم ربات تلگرام» توکن BotFather و شناسهٔ ادمین را وارد کنید.
4. حالت «وب‌هوک» را انتخاب کنید، تنظیمات را ذخیره کنید و «ست کردن وب‌هوک» را بزنید.
5. در تلگرام `/start` بفرستید. برای مدیریت، `/admin` را بزنید یا از دکمهٔ مدیریتِ ادمین استفاده کنید.
6. برای اتصال کانال (اختیاری)، ربات را مدیر کانال کنید، شناسه را در بخش «اتصال کانال» وارد و پیام آزمایشی را ارسال کنید؛ سپس انتشار خودکار را در صورت نیاز روشن کنید.

فیلد توکن پس از ذخیره دوباره در HTML نمایش داده نمی‌شود؛ توکن تازه را برای تغییر وارد کنید و برای حفظ مقدار فعلی، فیلد را خالی بگذارید. ثابت‌های `AHANGBAN_BOT_TOKEN`, `AHANGBAN_ADMIN_IDS`, `AHANGBAN_BOT_USERNAME` در wp-config.php بر تنظیمات دیتابیس اولویت دارند.

== ارسال فایل و مدیریت ==
* دکمهٔ دانلود ابتدا از Telegram Bot API برای دریافت پیوند واقعی استفاده می‌کند.
* اگر تلگرام نتواند فایل را دریافت کند، افزونه URL HTTPS عمومی را با بررسی مقصد/تغییرمسیر و سقف ۴۹ MiB از هاست دریافت و با cURL به تلگرام بارگذاری می‌کند.
* برای فایل‌های خیلی بزرگ، نشانی نامعتبر یا محدودیت‌های هاست، پیوند واقعی منبع و صفحهٔ اثر نمایش داده می‌شود؛ URL ساختگی تولید نمی‌شود.
* ارسال صوت، ویدیو و فایل آلبوم متناسب با نوع فایل انتخاب می‌شود. `file_id` فایل‌های صوتی برای ارسال مجدد در transient وردپرس cache می‌شود.
* پنل `/admin`: آمار کاربران/جست‌وجو/ارسال فایل، بررسی سلامت، پاک‌سازی cache، راهنمای مسدودسازی و پیام همگانی.
* اتصال اختیاری کانال در پیشخوان: اعلام آثار موسیقی تازهٔ تأییدشده (نوع `musics_type` شناخته‌شده یا متافیلد رسانهٔ قالب) با WP-Cron؛ نوشته‌های معمولی نادیده گرفته می‌شوند. برای deep-link به ربات باید یوزرنیم ربات تنظیم باشد. انتشار خودکار خاموش است تا مدیر آن را فعال کند.
* دستورات ادمین: `/block <user_id>`, `/unblock <user_id>`, `/broadcast <text>`؛ پیام همگانی پیش‌نمایش و تأیید دارد و با WP-Cron دسته‌ای ارسال می‌شود.
* شناسهٔ تلگرام و آمار حداقلی تعامل در جدول‌های افزونه در همان پایگاه‌دادهٔ وردپرس نگه‌داری می‌شوند؛ پایگاه‌دادهٔ جدا برای داده‌های وردپرس ساخته نمی‌شود.

== امنیت ==
* فقط نوشته‌های `publish` در API آهنگ‌ها برگردانده می‌شوند.
* توکن ربات و Secret وب‌هوک در `wp_options` با `autoload=no` ذخیره می‌شوند.
* وب‌هوک POST پس از تنظیم Secret، هدر `X-Telegram-Bot-Api-Secret-Token` را اجباری بررسی می‌کند.
* rate limit و شناسهٔ update تکراری کنترل می‌شوند؛ درخواست‌های تکراری یک‌بار پردازش می‌شوند.
* فایل منبع باید HTTPS باشد؛ IP خصوصی/رزروشده، مقصد محلی و redirect ناامن رد می‌شوند.

* اتصال اختیاری کانال با انتشار خودکارِ آهنگ‌های تازه از صف WP-Cron و پیام تست از پیشخوان؛ خاموش به‌صورت پیش‌فرض
* دکمهٔ کانال به ربات با deep link به همان اثر واقعی سایت
* رفع ارسال تکراری کارت و منوی شروع، و بهبود جست‌وجوی خواننده
* شمارش دسته‌های آثار هر خواننده با aggregation در SQL و کش؛ بدون بارگذاری همهٔ نوشته‌ها در PHP

= 1.3.0 =
