# شناسهٔ قابل‌جست‌وجو در کپشن کانال

از افزونهٔ AhangBan Connector **v1.6.10** به بعد، کپشن پست موسیقی مطابق این ترتیب ساخته می‌شود:

```text
🗣 عرشیاس

🎵 یعنی نمیای

🎤 #عرشیاس

🔖 شناسه اثر:

#AhangBan_15787

🔗 مشاهده صفحه رسمی

🆔️ @Ahangban_ir 💙
```

عدد نمونه است و از **شناسهٔ واقعی پست WordPress** می‌آید. هشتگ فقط شناسهٔ اثر را نشان می‌دهد و در جست‌وجوی Telegram می‌توان خود `#AhangBan_15787` را جست‌وجو کرد. این شناسه، `message_id` تلگرام نیست.

## رفتار انتشار

- انتشار خودکار WordPress و انتشار دستی کانال (از جمله درخواستی که Python به endpoint WordPress می‌فرستد) از کپشن‌ساز مشترک استفاده می‌کنند.
- هشتگ شناسه در سقف طول کپشن حفظ می‌شود.
- Voice Note یک کپشن جداگانه دارد و این تغییر روی آن اعمال نمی‌شود.
- پست‌های قبلی Telegram ویرایش نمی‌شوند؛ قالب تازه از انتشارهای بعدی فعال است.
- برای این تغییر افزونه را در پیشخوان WordPress به v1.6.10 ارتقا بده؛ **Redeploy Python لازم نیست**.
- اگر برای «متن پایانی کپشن کانال» متن سفارشی ذخیره شده باشد، آن متن همچنان بین لینک صفحه و امضای کانال می‌آید. برای خروجی دقیقاً مطابق نمونه، آن فیلد را خالی بگذار.

## یادآوری دربارهٔ پسندها پس از Redeploy

پسندها و دنبال‌کردن‌های حالت Python در SQLite محلی ربات‌اند، نه در افزونه یا WordPress. اگر فایل‌سیستم PaaS موقت باشد، Redeploy ممکن است ربات را به یک دیتابیس خالی وصل کند. برای جلوگیری از تکرار، Persistent Disk را فعال و `AHANGBAN_DB_PATH` را روی مسیر واقعی همان disk تنظیم کن؛ پیش از هر Redeploy هم backup فایل قدیمی را نگه دار. مسیر mount را حدس نزن. افزونهٔ WordPress لایک‌های محلی Python را پاک یا بازیابی نمی‌کند.
