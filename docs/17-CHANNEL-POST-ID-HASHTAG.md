# هشتگ شناسهٔ پست در کپشن کانال

از افزونهٔ AhangBan Connector **v1.6.9** به بعد، کپشن هر پست موسیقیِ تازه‌ای که به کانال ارسال می‌شود، در انتها یک هشتگ مستقل دارد:

```text
#ahangban_post_12345
```

`12345` نمونه است؛ مقدار واقعی از ID پست WordPress گرفته می‌شود. هشتگ فقط همین شناسه را در خود دارد و با جست‌وجوی همان هشتگ در Telegram قابل پیدا کردن است. کپشن طوری محدود می‌شود که هشتگِ انتهایی حذف نشود.

## دامنهٔ اثر

- کپشن انتشار خودکار WordPress و انتشار دستی از پنل PHP یک تابع مشترک دارند؛ هر دو هشتگ را می‌گیرند.
- فرمان انتشار دستی Python هم از endpoint امن WordPress استفاده می‌کند؛ ساخت کپشن همچنان در افزونهٔ WordPress است.
- این هشتگ به کپشن **پست اصلی** اضافه می‌شود، نه به Voice Note جداگانه.
- پست‌هایی که پیش از نصب v1.6.9 در Telegram منتشر شده‌اند ویرایش نمی‌شوند؛ هشتگ از انتشارهای بعدی اعمال می‌شود.
- برای این تغییر به Redeploy سرویس Python نیازی نیست؛ نسخهٔ افزونه را از پیشخوان WordPress به‌روزرسانی کنید.

## بازیابی پسندهای محلی

پسندها و دنبال‌کردن‌های حالت Python در فایل محلی SQLite ربات ذخیره می‌شوند، نه در افزونه یا دیتابیس WordPress. اگر فایل‌سیستم PaaS موقت باشد، Redeploy می‌تواند یک دیتابیس خالی بسازد. پیش از Redeploy بعدی، دیسک پایدار و `AHANGBAN_DB_PATH` را به مسیر واقعی همان دیسک متصل کنید و هر فایل قدیمی/backup را نگه دارید؛ مسیر mount را حدس نزنید. افزونهٔ v1.6.9 دادهٔ لایک را پاک یا بازیابی نمی‌کند.

## بسته و راستی‌آزمایی

- ZIP افزونهٔ v1.6.9: `releases/ahangban-connector-1.6.9.zip`، حجم ۷۸٬۴۶۷ بایت، SHA-256: `6071f7b43d09e9d17b0c007d51f7f1f1b272d743213985f544a7de89a8c1adf0`؛ `unzip -t` موفق بود.

- اجرای WordPress زنده یا انتشار آزمایشی در کانال انجام نشده است.
