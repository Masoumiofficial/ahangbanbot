# رادیوی آنلاین در ربات و کانال

<div dir="rtl" align="right" lang="fa">

## آنچه افزوده شده

- دکمهٔ «📻 رادیوی آنلاین» در منوی ربات و دستور عمومی `/radio` که صفحهٔ `https://ahangban.ir/radio/` را باز می‌کنند.
- دستور ادمین `/radio_post` در گفتگوی خصوصی ربات، که با API احرازشده از افزونهٔ WordPress یک پیام پیونددار را به مقصد کانال ذخیره‌شده در WordPress می‌فرستد. پس از انتشار، پیام را از خود Telegram سنجاق کنید تا دسترسی به پیوند دائمی باشد. برای این API افزونهٔ **AhangBan Connector v1.6.7 یا جدیدتر** لازم است.
- worker اختیاری FFmpeg برای فرستادن صدای رادیوی مستقیم به یک Telegram Live Stream که از قبل در کانال باز شده باشد. وقتی متغیرهای لازم موجود نباشند، worker خاموش می‌ماند و ربات عادی کار می‌کند.

## محدودیت مهم Telegram

Bot API به‌تنهایی نمی‌تواند Live Stream جدیدی در کانال ایجاد یا نشست بسته‌شده را دوباره باز کند. برای صدای واقعی و پیوسته داخل کانال، ادمین کانال باید یک Live Stream با ورودی RTMP/RTMPS ایجاد و باز نگه دارد؛ worker فقط به سرور همان نشست صدا/تصویر می‌فرستد. پس از پایان نشست Telegram، باید نشست تازه بسازید و نشانی/کلید تازه را در تنظیمات خصوصی سرویس بگذارید.

آدرس صفحهٔ `/radio/` برای بازشدن رادیو در مرورگر است، نه لزوماً آدرس مستقیم صوت. worker به URL مستقیم و عمومی HTTPS فایل/جریان صوتی (مثلاً HLS یا MP3) احتیاج دارد. آن URL باید از PaaS قابل دریافت باشد. **هیچ توکن یا کلید RTMP را در گفتگو، اسکرین‌شات، Git یا لاگ قرار ندهید.**

## تنظیم اختیاری در AbrhaPaaS

در بخش **Runtime Variables** اپلیکیشن این مقادیر را تنظیم کنید:

| نام | مقدار |
|---|---|
| `RADIO_STREAM_URL` | URL مستقیم صوت روی HTTPS؛ نه URL صفحهٔ رادیو |
| `RADIO_RTMP_SERVER` | نشانی RTMP یا RTMPS که Telegram برای Live Stream کانال نشان می‌دهد |
| `RADIO_RTMP_KEY` | کلید همان نشست Live Stream؛ Secret محرمانه |

worker فقط وقتی هر سه مقدار `RADIO_STREAM_URL`, `RADIO_RTMP_SERVER`, `RADIO_RTMP_KEY` تنظیم شده باشند اجرا می‌شود. آن‌ها را در بخش Build Variables نگذارید. `RADIO_RTMP_KEY` از متغیرهای محیطی خوانده می‌شود؛ کد عمداً URLها یا کلید را log نمی‌کند. اگر تنظیم ناقص یا نامعتبر باشد، ربات بالا می‌آید ولی پخش زنده آغاز نمی‌شود.

FFmpeg از بستهٔ `imageio-ffmpeg` می‌آید و صدا را به AAC/H.264 با پس‌زمینهٔ آبی ساده تبدیل می‌کند. PaaS باید فرایند طولانی‌مدت و اتصال خروجی RTMP/RTMPS را مجاز بداند. اگر Build به‌خاطر Package Registry شکست بخورد، worker جدید نصب/اجرا نمی‌شود؛ ذخیرهٔ متغیرهای Runtime به‌تنهایی Build را تعمیر نمی‌کند.

## انتشار پیوند به کانال

1. افزونهٔ WordPress را به v1.6.7 یا جدیدتر ارتقا دهید و مطمئن شوید مقصد کانال در تنظیمات WordPress وارد شده و ربات مدیر کانال است.
2. پس از استقرار نسخهٔ ربات دارای این قابلیت، در گفتگوی خصوصی ربات با حساب ادمین `/radio_post` بفرستید. API وردپرس یک بار پیام پیونددار منتشر می‌کند.
3. پیام تازه را در کانال سنجاق کنید. اگر پاسخ ارسال نامشخص بود، ابتدا کانال را بررسی کنید و فوراً دستور را دوباره اجرا نکنید تا پیام تکراری ساخته نشود.
