# کپشن Voice Note کانال — افزونهٔ 1.6.6

<div dir="rtl" align="right" lang="fa">

در نسخهٔ 1.6.6، کپشن Voice Note پیش‌نمایش کانال تنظیم مستقل دارد. این تنظیم با «متن تکمیلی کپشن کانال» فرق می‌کند: تنظیم قبلی فقط کپشن کارت/پست را تغییر می‌دهد و فیلد تازه فقط کپشن پیام صوتی را کنترل می‌کند.

## مقدار پیش‌فرض

```text
🩵 @AhangBan_ir 🩵

🎧 آهنگ بان | موسیقی همیشه همراهته 🎵
```

## تنظیم در پیشخوان

در پیشخوان WordPress، صفحهٔ «آهنگ‌بان API» و کارت «اتصال کانال تلگرام»، فیلد **کپشن پیش‌نمایش ویس کانال** را ویرایش کنید. متن ساده و چندخطی پذیرفته می‌شود؛ حداکثر طول ۹۰۰ نویسه است. برای ارسال Voice Note بدون کپشن، فیلد را خالی ذخیره کنید.

همین مقدار هنگام ارسال پیش‌نمایش از مسیر PHP وردپرس و هنگام fallback ربات Python استفاده می‌شود. اگر Voice Note از تنظیمات کانال خاموش باشد، این فیلد اثری روی پست کانال ندارد. کپشن کارت/پست و تنظیمات انتشار دیگری تغییر نمی‌کنند.

## ارتقا

فایل `releases/ahangban-connector-1.6.6.zip` را از بخش افزونه‌های پیشخوان بارگذاری و جایگزین کنید. پس از ارتقا، کپشن پیش‌فرض نمایش داده می‌شود؛ تنظیمات قبلی، از جمله «متن تکمیلی کپشن کانال»، مستقل باقی می‌مانند.

## راستی‌آزمایی محلی

- `pytest -q bot/tests` — **۹۶ آزمون موفق**.
- Ruff روی فایل‌های Python تغییرکرده، `compileall` و `git diff --check` — موفق.
- ZIP با ساختار نصب‌پذیر `ahangban-connector/` ساخته و با `unzip -t` بررسی شد؛ حجم ۷۶٬۳۰۲ بایت، SHA-256: `3e938c69f88c7d18adefe74d7ffedb83408040a7f0be3df022772522452cf038`.
- PHP در این محیط نصب نیست، بنابراین `php -l` اجرا نشد؛ در عوض parser با دستور زبان PHP 7 فایل‌های PHP افزونه را parse کرد و خطای نحوی گزارش نکرد.
- WordPress زنده و کانال تلگرام در دسترس آزمون نبودند؛ ارسال واقعی تأیید نشده است.
